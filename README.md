# LogGuard — анализатор SSH-логов для поиска brute-force атак

LogGuard — простой скрипт на Python для выявления подозрительных попыток входа по SSH.
Работает на стандартной библиотеке, внешние зависимости не нужны.

## Возможности

- Парсит типичные строки `auth.log` (формат Debian/Ubuntu).
- Считает количество неудачных попыток входа (`Failed password`) по IP.
- Определяет brute-force атаки по скользящему окну времени.
- Выводит отчёт в терминал, а также в CSV и JSON.

## Как запустить

```bash
python logguard.py sample_auth.log
python logguard.py sample_auth.log --window 5 --threshold 3 --csv report.csv
python logguard.py sample_auth.log --json report.json
```

### Параметры

- `--window` — окно анализа в минутах (по умолчанию 10).
- `--threshold` — порог попыток в окне для срабатывания флага brute-force (по умолчанию 5).
- `--csv` — путь для сохранения CSV-отчёта.
- `--json` — путь для сохранения JSON-отчёта.

## Пример вывода

```text
LogGuard: 14 failed-попыток, 3 уникальных IP

IP                  Fails  Users                    Period                        Flag
----------------------------------------------------------------------------------------------
203.0.113.45           12  admin, root              02:11 - 02:13                 BRUTE-FORCE
192.168.1.50            2  admin                    03:40 - 03:40
```

## Технические детали

- Язык: Python 3
- Зависимости: только стандартная библиотека
- Формат логов: строки вида `... sshd[...]: Failed password for ... from ...`

## Зачем это нужно

Скрипт решает типичную задачу SOC-аналитика: быстро найти IP с признаками
brute-force по сырым логам. Может использоваться как основа для пайплайна
обработки логов или как учебный пример работы с регулярными выражениями
и временными окнами.
